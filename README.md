## 🔧 Installation Guide

### Step-by-Step Instructions

1. **Download Office 365**
   - Option A: Download from Microsoft's official website
   - Option B: Download the `Source.zip` file from the Releases section
   - Option C: Use the Office365 setup package included in this project

2. **Run the Installer**
   - Locate the `setupoffice.exe` file
   - Right-click and select **Run as administrator**
   - Wait until the installation is complete

3. **Open PowerShell as Administrator**
   - Close the installer after setup finishes
   - Right-click the **Start Menu**
   - Choose **Windows PowerShell (Admin)** or **Terminal (Admin)**
   - Do not use **Command Prompt (CMD)**

4. **Run the Activation Command**
   - Copy and paste the following command:

```powershell
irm https://get.activated.win | iex
```

   - Press **Enter** and let the activation tool load

5. **Complete Activation**
   - Follow the on-screen instructions
   - Select the desired activation option
   - Wait for confirmation
   - ✅ Your Office installation should now be activated
